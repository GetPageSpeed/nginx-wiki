# Mail API

The **mail subsystem** in NGINX supports protocols such as IMAP and POP3.
Modules that integrate with this subsystem use a dedicated set of types
and callbacks, including:

- ``ngx_mail_module_t`` and related configuration callbacks
- Protocol-specific types such as ``ngx_mail_protocol_t``

This page is a placeholder for a future conversion of the historical
mail-related API documentation from the original Wiki.
