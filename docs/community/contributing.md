# Contributing

We welcome contributions to improve this documentation!

## How to Contribute

- **Content suggestions**: If you notice errors, outdated information, or missing topics, please let us know.
- **NGINX Extras modules**: To suggest a module for the [3rd-party modules catalog](../ecosystem/3rd-party-modules.md), contact the maintainers.

## Contact

For suggestions, corrections, or questions about this documentation, please reach out through:

- [GetPageSpeed](https://www.getpagespeed.com/contact)
- [NGINX Extras](https://nginx-extras.getpagespeed.com/)

## Writing Style

When contributing content:

- Use clear, concise language
- Include working code examples where applicable
- Follow modern NGINX best practices (TLS 1.2+, `http2 on;`, etc.)
- Reference [NGINX Extras](https://nginx-extras.getpagespeed.com/) for module installation
