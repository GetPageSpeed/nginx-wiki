# IRC Operator Guidelines

## Best Practices

- **Stay friendly** - Warn first, remove if necessary. Never swear. Stay calm.
- **Don't hold ops** - De-op yourself after handling issues. Use +o only when needed.
- **Don't use /ignore** - Use soft-ignore instead. +g user mode blocks PMs if needed.
- **Clean bans regularly** - Users usually learn; don't leave bans forever.
- **Comment on bans** - Use ngxbot to track why bans were made.
- **Don't retaliate** - Take only appropriate actions. Retaliation looks bad.

## When to Ban/Kick

| Situation | Action |
|-----------|--------|
| Flooding | Mute |
| Accidental paste | Mute + point to pastebin |
| Swearing/off-topic | Warn |
| Repeated offense | Quiet |
| Returning after kick | Ban |
| Trolling | Ban |
| Personal attacks | Kick/ban |

## Examples of Trolling

- Repeatedly asking about other web servers/OSs
- Testing limits of what's allowed
- Excessive CAPS
- Being only negative

## Accidents Happen

Ops can be trigger-happy. Recognize accidents and respond proportionally. Users make mistakes too.
